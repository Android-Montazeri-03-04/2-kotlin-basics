## **۴. متغیرها و انواع داده‌ها** 📝

| نوع داده‌ای  | توضیح                 | مثال |


## **۷. تمرین‌های کاربردی حلقه‌ها**

### تمرین ۷-۱: محاسبه میانگین نمرات با آرایه و حلقه  
نوشتن برنامه‌ای که میانگین نمرات یک آرایه را بدون استفاده از توابع آماده مثل `sum()` محاسبه کند:

```kotlin
fun main() {
    val scores = arrayOf(18, 15, 20, 17, 14)
    var sum = 0
    for (score in scores) {
        sum += score
    }
    val average = sum.toDouble() / scores.size
    println("میانگین نمرات: $average")
}
```

***

### تمرین ۷-۲: محاسبه میانگین نمرات با لیست و ورودی کاربر بدون چک کردن null  
برنامه‌ای که تعداد نمرات را از کاربر بگیرد، نمرات را دریافت کند و با استفاده از حلقه میانگین آنها را محاسبه کند:

```kotlin
fun main() {
    print("تعداد نمرات را وارد کنید: ")
    val n = readLine()!!.toInt()

    val scores = mutableListOf<Int>()
    var sum = 0

    for (i in 1..n) {
        print("نمره $i را وارد کنید: ")
        val score = readLine()!!.toInt()
        scores.add(score)
        sum += score
    }
    val average = sum.toDouble() / n
    println("میانگین نمرات: $average")
}
```

***

### تمرین ۷-۳: محاسبه مجموع اعداد وارد شده تا وارد کردن عدد صفر (مثال کاربردی حلقه while)

```kotlin
fun main() {
    var sum = 0
    var number: Int

    println("اعداد را وارد کنید (برای پایان صفر را وارد کنید):")
    while (true) {
        number = readLine()!!.toInt()
        if (number == 0) {
            break
        }
        sum += number
    }

    println("مجموع اعداد وارد شده: $sum")
}
```

### توضیح:
- حلقه به صورت نامحدود اجرا می‌شود تا زمانی که عدد صفر وارد شود.  
- بعد از وارد کردن صفر، حلقه با دستور `break` متوقف می‌شود.  
- در هر مرحله عدد وارد شده به مجموع اضافه می‌گردد.  
- این تمرین کاربردی و ساده دانشجویان را با مفاهیم حلقه، دریافت ورودی، و کنترل شرط خاتمه حلقه آشنا می‌کند.

## **۸. بازی حدس عدد** 🎯
✏️ **تمرین ۵**: برنامه‌ای بنویسید که یک عدد تصادفی بین ۱ تا ۱۰۰ انتخاب کند. کاربر باید در **۵ حدس** عدد را پیدا کند. بعد از هر حدس، برنامه باید بگوید عدد وارد شده **بزرگ‌تر** یا **کوچک‌تر** از عدد موردنظر است. اگر کاربر عدد صحیح را در ۵ حدس پیدا نکرد، پیام شکست نمایش داده شود.

💡 **راهنمایی:** از `Random.nextInt(1, 101)` برای تولید عدد تصادفی و از `while` یا `for` برای تعداد حدس‌ها استفاده کنید.

### **راه‌حل پیشنهادی:**
```kotlin
import kotlin.random.Random

fun main() {
    val target = Random.nextInt(1, 101)
    var attempts = 5

    println("یک عدد بین ۱ تا ۱۰۰ حدس بزنید!")
    while (attempts > 0) {
        print("حدس شما: ")
        val guess = readln().toInt()

        if (guess == target) {
            println("تبریک! عدد را درست حدس زدید 🎉")
            return
        } else if (guess < target) {
            println("عدد بزرگ‌تر است ⬆️")
        } else {
            println("عدد کوچک‌تر است ⬇️")
        }
        attempts--
    }
    println("متاسفم! عدد موردنظر $target بود ❌")
}
```
